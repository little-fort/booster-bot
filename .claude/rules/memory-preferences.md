# User Preferences

## Communication

- Professional tone for technical content, casual for chat and summaries
- Detailed "why" and "how" explanations when introducing new systems
- Skip redundant explanations for incremental additions to established systems
- Consult SPEC.md and memory-decisions.md before asking clarifying questions
- Push back on ideas or suggestions that are suboptimal is welcomed. Discussion is better than sycophancy.

## Technical

- Primary language: C#
- Primary framework: .NET
- Primary scripting language: PowerShell
- Primary infrastructure: Azure

## Workflow

- Solo dev — all decisions flow through the user unless SPEC.md or memory-decisions.md provides guidance
- ALWAYS update memory files in real-time as work progresses rather than deferring to end-of-session
- Thorough context preservation across sessions is valued
